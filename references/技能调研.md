## 二、必须借鉴的三个机制

### 2.1 检查点机制（blind-review-skill 最核心的设计）

它在关键节点**停下来问用户**，而不是一次跑完：

```
🛑 检查点1（快速扫描后）：结构识别和学科判断是否正确？有无重点章节？
🛑 检查点2（逐章审查后）：交叉验证发现，是否属实？
🛑 检查点3（评分前）：默认权重是否调整？评分是否合理？
🛑 检查点4（交付前）：完整性自检
```

**这直接解决我这次犯的错**——我一次写 31 条批注，全错也发现不了。
正确做法：**先给你看“我发现了什么”清单，你确认后我再写进 Word。**

### 2.2 「未报告」≠「做得差」（blind-review-skill）

> 「未报告」不同于「做得差」：✗（未报告）最多使评分降至 3 分，不应直接判为 1-2 分（除非是关键检查项缺失）

我这次犯的正是这个错：
- “第一章内容太少” → 实际 3783 字，是我没数
- “图4.2题注在上方” → 实际在下方，是我没看图

**规则：任何判断必须先取得证据，拿不到证据就标“未报告/待确认”，不下结论。**

### 2.3 致命伤 vs 皮外伤（blind-review-skill）

```
学术规范（抄袭/数据造假/引用不当）
  > 方法缺陷
    > 写作问题
      > 格式问题
```

这条决定了批注优先级。**格式问题再严重也是次要的，引用造假才是致命的。**

## 三、六维度评分体系（可直接用于生成报告）

| 维度 | 权重 | 检查重点 |
|---|---|---|
| 选题与工作量 | 15% | 选题意义、工作量是否充足 |
| 研究方法与规范性 | 25% | 方法是否合理、步骤是否可复现 |
| 数据分析与结果呈现 | 20% | 数据完整性、图表规范 |
| 讨论与论证质量 | 15% | 是否解释结果、是否联系文献 |
| 写作与结构 | 15% | 章节安排、语言表达 |
| 文献与学术规范 | 10% | 引用闭环、格式 |

**桥接规则**：检查项结果（✓/⚠/✗）映射到 1-5 分
- 全 ✓ 或仅 1 个 ⚠ → 5 分
- 2-3 个 ⚠ → 4 分
- 半数 ⚠ 或 1-2 个 ✗ → 3 分
- 多个 ✗ → 2 分
- 几乎全 ✗ → 1 分

## 四、三视角评阅（可用于生成正式评语）

| 视角 | 侧重 | 语气 |
|---|---|---|
| 指导教师 | 研究过程、工作量、方法掌握 | 亲切肯定 |
| 评阅专家 | 学术质量、创新性、科学性 | 客观冷静 |
| 答辩委员会 | 陈述表现、问题回答、综合评价 | 正式庄重 |

**用途**：这三份是正式存档材料，跟给学生改的批注是两回事。批注用你的口语风格，评语用这个正式格式。

## 五、整合到现有流程

```
Phase 0  事实核查（新增，必做）
         ├─ 数字数：各章字数、摘要字数、结论字数
         ├─ 数图表：图数量、表数量、题注位置
         ├─ 查引用：每章 [n] 标注数量
         ├─ 查格式：字体字号、页码、分节
         └─ 查结构：章节完整性、小标题
              ↓
Phase 1  生成「问题清单」给教师看（检查点1）
         ├─ 每条带：段落号 + 原文片段 + 客观依据 + 建议批注
         └─ 教师勾选：要批 / 不批 / 改措辞
              ↓
Phase 2  只写勾选的批注（检查点2）
              ↓
Phase 3  生成三视角正式评语（可选）
```
